---
title: 'Upgrade viewers'
openapi: 'POST /purchases/{orderId}/upgrade-viewers'
---

1. [Get a quote](/api-reference/endpoints/purchases/actions/upgrade-viewers-quote) for the new total viewer limit.
2. Send the same `target_viewers` and the quoted `amount` as `max_amount`.
3. Read the actual cost from `amount` and the payment ID from `payment_id`.

If the cost exceeds `max_amount`, the API returns `409 price_changed` without applying the upgrade. Request a new quote before trying again. Omit `max_amount` or pass `null` to allow the upgrade without a spending limit.

The upgrade increases the viewer limit without extending the order duration. In the response, `status: "completed"` refers to the upgrade payment; the original order can continue running.
